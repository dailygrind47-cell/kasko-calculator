# Калькулятор КАСКО

## Как получить .exe файл

1. Дождитесь завершения сборки (зеленая галочка в Actions)
2. Перейдите во вкладку "Actions"
3. Выберите последний workflow run
4. В разделе "Artifacts" скачайте `KASKO_Calculator_Windows`
5. Распакуйте архив и запустите `KASKO_Calculator.exe`

## Использование

Просто запустите .exe файл - никаких дополнительных установок не требуется!
